System Design

From sensor matrix to doorway intelligence.

The firmware reads MLX90640 frames, builds a temperature mask, extracts connected thermal regions, and tracks each center across frames. The dashboard receives either serial or WiFi frames, renders the thermal field, and exposes counts that are readable during a live demo.

Repository Architecture

Named like a real product, structured like a real system.

The old scratch-folder names are gone. Firmware, dashboards, and documentation now sit in clear modules, so reviewers can understand the project before opening a single file.

firmware/edge_counterESP32-side detection, tracking, and entry/exit counting.
firmware/wifi_streamAccess-point TCP stream for wireless thermal frames.
firmware/serial_streamHigh-throughput serial thermal matrix transmitter.
software/thermal_dashboardPython visualizers for serial, WiFi, optimized, and CLI modes.

Code Map

Every entry point has a job.

Python Fast thermal dashboard

 Python WiFi control dashboard

 Arduino Edge counter firmware

Memory-conscious ESP32 firmware with center output, FPS reports, and pause control.
